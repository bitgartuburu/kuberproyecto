# Proyecto Kubernetes

## Justificación del proyecto

Es proyecto pretende servir cómo ruta de  aprendizaje para cubrir un espectro amplio de competencias
desde el desarrollo de una aplicación conectada por distintas APIs, hasta su despliegue en Kubernetes.
Para ello, voy a desarrollar un aplicación sencilla: un lista de tareas que conecte con un calendario 
y una interfaz web, una aplicación partida en 3 piezas, que serán contenerizadas y desplegada con Kubernetes.

## Puntos del proyecto:
- Creación de la aplicación
    - Aplicación notas
    - Aplicación calendario
    - Aplicación interfaz web
- Integración de Kubernetes
